# English Academy — Từ mất gốc A0 đến B2

Website tự học tiếng Anh miễn phí bằng tiếng Việt, dành cho người mới bắt đầu.

## Tính năng
- Học theo 5 cấp độ A0, A1, A2, B1, B2.
- Bài giảng, flashcards từ vựng, bài tập và chấm điểm.
- Luyện nghe bằng giọng đọc của trình duyệt; luyện nói qua micro khi trình duyệt hỗ trợ.
- Theo dõi tiến độ và lưu kết quả trên thiết bị.
- Không yêu cầu tài khoản hoặc API trả phí.

## Chạy trên máy tính
Tải file `index.html` về máy và mở bằng Chrome hoặc Edge.

## Đưa website lên GitHub Pages
1. Vào repository **Settings** → **Pages**.
2. Trong **Build and deployment**, chọn **Deploy from a branch**.
3. Chọn nhánh **main**, thư mục **/(root)**, nhấn **Save**.
4. Khi Pages triển khai xong, mở https://quang-vu-stack.github.io/tin_anh/

## Lưu ý dữ liệu
Website lưu tiến độ tại trình duyệt hiện tại. Khi đổi thiết bị hoặc xóa dữ liệu trình duyệt, hãy dùng chức năng xuất/nhập bản sao lưu JSON trong web. Tính năng micro cần trình duyệt hỗ trợ và quyền cho phép.
